# Maternal Health RAG System
Development of a Context-Aware Maternal Health System using Retrieval-Augmented Generation (RAG)

# Project Overview
This repository hosts the development of an Information Systems Project, titled "Retrieval-Augmented Generation for Contextualized 
Maternal Health Information Delivery and Use in Low-Resource Settings."

The project seeks to address challenges faced by expectant mothers in accessing reliable maternal health information, particularly in low-resource settings. The proposed solution utilizes Retrieval-Augmented Generation (RAG) to retrieve information from trusted maternal health knowledge sources and generate context-aware responses.

# Objectives

The project aims to:

i)	To identify the system requirements for a maternal health chatbot that assists expectant mothers in timely recognition of danger signs and informed decision making of when to seek for medical help.<br>

ii)	To review and assess the retrieval, augmentation and generation methods suitable for implementing a RAG maternal health system.<br>

iii) To develop a context aware maternal health system that captures the patient’s context in terms of where they are located at, their gestational period, and medical history.<br>

iv)	To evaluate the retrieval quality, contextual relevance, and response groundedness of the developed RAG system in identifying maternal danger signs and recommending appropriate healthcare-seeking actions.<br>
